# Temporäre Bilder

Dieser Ordner enthält Übergangsassets aus der bestehenden Website.

- Nur freigegebene Bilder ohne sichtbare Patientendaten, Dokumente oder Monitore ablegen.
- Dateinamen sprechend und mit `-temp` kennzeichnen, zum Beispiel `fortelny-portrait-temp.webp`.
- Vor Go-live Nutzungsrechte, Bildfreigaben und finale Ersetzung prüfen.
