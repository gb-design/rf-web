# Impeccable Design Context — Dr. René H. Fortelny Website

## Project

Neue moderne Desktop und mobil optimierte Arztpraxis-Website für Dr. René H. Fortelny (Chirurg, Univ.Prof.Dr., Wien). Kombination aus professionellem Surgeon Portfolio und Patienteninformationsseite. Gebaut auf Astro 5 + Sanity CMS, gehostet auf Cloudflare Pages.

## Webseite aktuell

URL: https://www.fortelny.at
Plattform: Webflow CMS Plan

---

## Target Audience

**Primär: Patienten**

- Österreich, alle Altersgruppen, überdurchschnittlich gebildet
- Sie suchen einen Chirurgen und medizinischen Berater aus der Hernienchirurgie — sind in einer ernsten oder zumindest angespannten Situation
- Brauchen: Vertrauen, Kompetenz, Klarheit — keine Ablenkung, keine Verspieltheit
- Gerät: Desktop und Mobile (häufig Erstkontakt auf Mobile)

**Sekundär: Medizinische Kollegen & Fachpublikum**

- Suchen akademische Informationen: CV, Publikationen, Vorträge, Goodies (Medic Cards, Präsentationen und Publikationen)
  – Wissensaustausch zwischen Studierenden und Kollegen
- Erwarten einen professionellen, akademischen Auftritt auf Augenhöhe

---

## Brand Personality

**Präzise. Vertrauenswürdig. Elegant.**

Nicht: modern-klinisch, startup-haft, generisch-medizinisch, überladen.

Referenz als physisches Objekt: das Briefpapier einer renommierten Wiener Privatordination, oder das Layout einer österreichischen Universitätspublikation — klare Linien, kühle Materialqualität, warm durch Typografie und Raumaufteilung.

## Color System

**Theme: Light-first mit dunklen Kontrastsektionen**

- Keine manuelle Umschaltung in der Navigation
- Keine gespeicherte User-Praeferenz
- Dunkle Flächen sind bewusst gesetzte Sektionszustände, z. B. für Hero, CTA oder Editorial-Breaks
- Scroll kann später genutzt werden, um Header/Navigation an die aktuelle Section-Tonalität anzupassen
- Implementierung: Light Tokens in `:root`, dunkle Sektions-Tokens in `[data-section-theme="dark"]`

```css
/* ── LIGHT MODE (default) ───────────────────────────── */
:root {
  --color-bg: oklch(0.97 0.005 220); /* nahe an brand-light, sehr hell */
  --color-surface: oklch(0.99 0.003 220);
  --color-surface-tint: oklch(0.93 0.025 220); /* brand-light = #E2ECF3 */

  --color-text: oklch(0.17 0.025 265); /* brand-dark = #212137 */
  --color-text-muted: oklch(0.5 0.015 240);
  --color-text-subtle: oklch(0.68 0.01 230);

  --color-border: oklch(0.88 0.015 220);
  --color-border-light: oklch(0.93 0.008 220);

  --color-primary: oklch(0.72 0.09 220); /* brand-blue #77B1E1 */
  --color-primary-deep: oklch(0.62 0.1 222);
  --color-primary-bg: oklch(0.93 0.025 220);

  --color-accent: oklch(0.54 0.19 352); /* brand-red #DA4378 */
  --color-accent-deep: oklch(0.45 0.18 350);
  --color-accent-bg: oklch(0.94 0.04 352);
}

/* ── DUNKLE SEKTION ─────────────────────────────────── */
[data-section-theme="dark"] {
  --color-bg: oklch(0.17 0.025 265); /* brand-dark = #212137 */
  --color-surface: oklch(0.21 0.022 265);
  --color-surface-tint: oklch(0.26 0.025 255);

  --color-text: oklch(0.95 0.01 220); /* near-white, blaustichig */
  --color-text-muted: oklch(0.68 0.015 230);
  --color-text-subtle: oklch(0.5 0.01 240);

  --color-border: oklch(0.3 0.02 260);
  --color-border-light: oklch(0.25 0.018 265);

  --color-primary: oklch(0.76 0.09 220); /* leicht heller auf dunklem Bg */
  --color-primary-deep: oklch(0.65 0.1 222);
  --color-primary-bg: oklch(0.25 0.035 240);

  --color-accent: oklch(0.65 0.18 352); /* heller auf dunklem Bg */
  --color-accent-deep: oklch(0.55 0.19 350);
  --color-accent-bg: oklch(0.25 0.05 355);

```

**Über brand-red (`#DA4378`):** Starker Kontrastakzent zum kühlen Blau. Sparsam einsetzen — sekundäre CTAs, Hover-States, Datums-Labels bei Events. Nicht als Flächenfarbe.

## Typography

**Bestehende Marken-Fonts (vom Kunden vorgegeben):**

- **IBM Plex Sans** — Alle Überschriften (H1–H6) und UI-Elemente
- **IBM Plex Serif** — Subheadlines, Fließtext, Paragraphen

IBM Plex ist ein IBM-designed System mit exzellenter Lesbarkeit und einem sauberen technisch-humanistischen Charakter. Die Sans/Serif-Kombination aus derselben Schriftfamilie erzeugt kohärente Hierarchie.

```css
--font-display: "IBM Plex Sans", system-ui, sans-serif; /* H1–H6, UI */
--font-body: "IBM Plex Serif", Georgia, serif; /* Body, Subheadlines */
```

**Google Fonts Import:**

```html
<link
  href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@300;400;500;600;700&family=IBM+Plex+Serif:ital,wght@0,300;0,400;0,500;1,400&display=swap"
  rel="stylesheet"
/>
```

**Typografische Hierarchie:**

```
H1 (Hero):    IBM Plex Sans, clamp(2.75rem, 5.5vw, 5rem),    weight 300, lh 1.1
H2 (Section): IBM Plex Sans, clamp(1.75rem, 3.5vw, 2.75rem), weight 400, lh 1.2
H3 (Sub):     IBM Plex Sans, clamp(1rem, 1.8vw, 1.2rem),     weight 600, ls 0.08em, uppercase
Body:         IBM Plex Serif, 1rem (16px), weight 400, lh 1.7, max-width 65ch
Label/Meta:   IBM Plex Sans, 0.8125rem, weight 500, ls 0.1em, uppercase, color: muted
Caption:      IBM Plex Serif, 0.875rem, weight 300, font-style italic
```

**Hinweis zu weight 300 bei H1:** IBM Plex Sans Light (300) bei großen Größen wirkt elegant und nicht schwer — passt zur "Präzise. Elegant."-Richtung.

## Layout & Space

4pt Spacing Scale: `4, 8, 12, 16, 24, 32, 48, 64, 96, 128`

Seiten atmen großzügig: weite vertikale Abstände zwischen Sektionen (64–128px), kompaktere Abstände innerhalb.

- Linksbündige Layouts — nicht alles zentriert
- Asymmetrie als Designmittel, nicht als Fehler
- Das Brand-Blau sparsam einsetzen — als Akzentfarbe, nicht als Flächenfarbe

---

## Key UI Patterns

**Navigation:** Minimal, nur Logo + max. 5 Items + CTA-Button. Kein Mega-Menu.

**Hero:** Große typografische Aussage (H1 in Garamond) + Foto. Kein Text-über-Bild-Overlay.

**Sections:** Getrennt durch Spacing, nicht durch Boxen oder Trennlinien.

**Cards (Events, etc.):**

- Keine Schatten, keine border-left accent stripes
- Trennung durch `1px border` (var(--color-border)) oder Spacing allein
- Kein Padding-Bloat — kompakt, informationsdicht

**Buttons:**

- Primär: solider Brand-Blau-Hintergrund, weißer Text, 100vw border-radius (oder max. 999px)
- Sekundär: text-link mit Unterstrich, kein Ghost-Button mit dickem border

**Fotos:** Vollflächig, ohne Rahmen, ohne übermäßige Rundungen. Groß zeigen.

---

## Anti-Patterns für DIESES Projekt

- Kein glassmorphism / blur effects
- Keine `border-left` accent stripes auf Cards oder Callouts
- Kein gradient text (`background-clip: text`)
- Keine Stock-Foto-Arzt-Ästhetik (Stethoskop-Clipart, Türkis-Grün)
- Keine Rundungen > 4px auf Containern
  – Maximale Rundung nur bei Buttons
- Keine Icon-Grid-Layouts mit identischen Cards (icon + heading + text, wiederholt)
- Kein Teal oder Grün — diese Farben sind medizinisches Klischee
- Keinen Intro-Text der die H1 nochmal wiederholt
